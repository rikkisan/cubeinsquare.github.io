Générateur de bossbar Minecraft

Préparez des piles de commandes bossbar pour événements RP, raids, rituels, comptes à rebours et alertes serveur. Choisissez l’ID, le titre, la couleur, le style, les joueurs et la progression, puis copiez une séquence propre pour command blocks ou fonctions datapack.

Préréglages rapides

Réglages bossbar

Une bossbar fonctionne mieux quand elle affiche un état : danger, charge rituelle, phase, temps d’évacuation ou pression publique du serveur. Cet outil crée les commandes de base ; un minuteur vivant doit encore être mis à jour par command block répétitif ou fonction datapack.

Commandes générées

Bossbar

  • /bossbar add
  • /bossbar set value
  • /bossbar set players
  • /bossbar remove

Utiliser le générateur

Le générateur écrit sept commandes /bossbar : une crée la barre, six la configurent. L’aperçu montre le titre, la couleur et le remplissage avant toute copie.

Partir d’un préréglage

Ritual charge, Raid phase II, Evacuation: 3 minutes et Phase break incoming remplissent tous les champs pour un événement typique. Changez l’identifiant avant de vous en servir, pour que deux événements ne partagent jamais une barre.

Deux noms

L’identifiant, par exemple cube:ritual_charge, permet aux commandes suivantes de retrouver la barre ; il s’écrit en minuscules et reçoit l’espace de noms cube: si vous n’en mettez pas. Le titre est ce que lisent les joueurs, en petit au-dessus de la barre : quelques mots suffisent.

Couleur et style

progress pour les minuteurs et tout ce qui est continu, un style à crans quand les joueurs doivent pouvoir compter les phases. Choisissez un nombre de crans qui divise votre maximum.

Max, valeur et joueurs

Max et value partagent une unité : secondes, phases, offrandes. Players décide qui voit la barre maintenant ; un joueur qui se connecte plus tard ne voit rien tant que la ligne n’est pas relancée.

Copier et lancer

Collez les lignes une par une dans le chat pour tester, une par bloc dans des blocs de commande, ou dans un fichier de fonction sans la barre oblique initiale.

Trois choses que les commandes ne font pas à votre place

Relancer

La ligne add échoue si l’identifiant existe déjà. Pour reconstruire une barre, lancez d’abord /bossbar remove ou sautez la première ligne.

Décompter

Une barre affiche la dernière valeur reçue. Un minuteur a besoin d’une boucle qui la met à jour ; l’article sur les événements donne un compte à rebours qui marche.

Ranger

Les barres personnalisées sont enregistrées avec le monde et survivent aux redémarrages. Lancez /bossbar remove à la fin de la scène, et /bossbar list pour repérer les oubliées.

Versions

Java Edition 1.13 à 26.3. Le titre est écrit {"text":"…","color":"white"} : le jeu le lit comme du JSON jusqu’en 1.21.4 et comme du SNBT depuis la 1.21.5, donc la même sortie fonctionne des deux côtés. Bedrock Edition n’a pas de commande /bossbar.
