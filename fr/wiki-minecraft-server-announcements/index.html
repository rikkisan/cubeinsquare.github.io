Comment faire des annonces sur un serveur Minecraft

Minecraft vanilla offre cinq façons de prévenir tous les joueurs à la fois : une ligne de chat avec /say, un message mis en forme avec /tellraw, un grand texte à l'écran avec /title, une ligne au-dessus de la barre d'objets et une barre de boss. Toutes fonctionnent depuis la console du serveur, un bloc de commande ou une fonction de data pack, sans plugin. Voici les commandes pour 1.21.5 – 26.x, ce qui change dans les versions plus anciennes et comment répéter un message à intervalle régulier.

Choisissez d'abord le canal

L'endroit où le message apparaît décide de la façon dont il est reçu. Le chat reste dans l'historique, le texte à l'écran interrompt, et une barre reste affichée jusqu'à ce que vous la retiriez.

/say : le plus rapide

Dans la console du serveur, on tape les commandes sans barre oblique ; dans le chat ou un bloc de commande, avec :

say Le serveur redémarre dans 10 minutes

Depuis la console, les joueurs voient [Server] Le serveur redémarre dans 10 minutes. Envoyée par un joueur, la ligne porte son pseudo, et depuis un bloc de commande le nom du bloc (@ si vous ne l'avez pas renommé). /say ne gère pas les couleurs, et un sélecteur comme @a dans le texte devient une liste de pseudos.

/tellraw : couleurs, infobulles et liens

/tellraw envoie un composant de texte aux joueurs choisis. Avec des clés entre guillemets, la même commande marche dans toutes les versions de 1.20 à 26.x : c'est du JSON valide pour les anciennes versions et du SNBT valide à partir de 1.21.5 :

tellraw @a {"text":"Le serveur redémarre dans 10 minutes","color":"gold","bold":true}

Les morceaux aux styles différents se mettent dans une liste :

tellraw @a [{"text":"[Événement] ","color":"red"},{"text":"L'arène ouvre à 18 h","color":"white"}]

Les infobulles et les liens cliquables sont l'endroit où les versions divergent. La 1.21.5 a renommé les champs : une commande copiée d'un ancien guide affiche son texte mais ne réagit ni au survol ni au clic :

1.21.5 – 26.x

tellraw @a {"text":"Lire le règlement","color":"aqua","underlined":true,"hover_event":{"action":"show_text","value":"Ouvre la page du règlement"},"click_event":{"action":"open_url","url":"https://example.com/rules"}}

1.20 – 1.21.4

tellraw @a {"text":"Lire le règlement","color":"aqua","underlined":true,"hoverEvent":{"action":"show_text","contents":"Ouvre la page du règlement"},"clickEvent":{"action":"open_url","value":"https://example.com/rules"}}

Les autres actions de clic ont changé de la même façon : depuis la 1.21.5, run_command et suggest_command prennent command au lieu de value. Le joueur confirme avant qu'un lien s'ouvre, et rien ne s'ouvre s'il a désactivé les liens web dans les paramètres du chat.

/title : grand texte, sous-titre et barre d'action

Un titre se règle en trois temps : la durée, le sous-titre, puis le titre. Le sous-titre attend l'arrivée d'un titre, il faut donc l'envoyer en premier :

title @a times 10 70 20
title @a subtitle {"text":"L'arène ouvre dans une minute","color":"gray"}
title @a title {"text":"ÉVÉNEMENT","color":"gold","bold":true}

Les nombres sont l'apparition, l'affichage et la disparition en ticks (20 ticks font une seconde) : ce titre reste donc environ cinq secondes. Limitez-le à un ou deux mots, le joueur le lit en bougeant. La barre d'action est une ligne plus discrète au-dessus de la barre d'objets :

title @a actionbar {"text":"PvP désactivé jusqu'à 18 h","color":"green"}

Elle s'efface au bout de quelques secondes. Pour garder une ligne affichée, pour un minuteur ou une alerte, renvoyez-la chaque seconde depuis une fonction comme celle ci-dessous. title @a clear efface l'écran, et title @a reset remet aussi la durée par défaut.

Des barres de boss pour les événements qui durent

Une barre de boss reste en haut de l'écran jusqu'à ce que vous la retiriez, ce qui convient aux événements et aux comptes à rebours :

bossbar add cube:event {"text":"Siège de la porte nord"}
bossbar set cube:event color red
bossbar set cube:event players @a
bossbar remove cube:event

Le générateur de barres de boss écrit l'ensemble complet avec valeur et style, et l'article sur les barres de boss pour les événements montre un compte à rebours qui fonctionne.

Répéter un message à intervalle régulier

Une fonction de data pack peut se relancer plus tard avec /schedule. Enregistrez ceci sous data/cube/function/broadcast.mcfunction (le dossier s'appelle functions avant la 1.21) :

tellraw @a {"text":"Prochain événement : samedi, 18 h à l'arène","color":"gray"}
schedule function cube:broadcast 6000t

Lancez function cube:broadcast une fois et le message revient toutes les 6000 ticks, soit cinq minutes à 20 ticks par seconde ; schedule clear cube:broadcast l'arrête. Pour faire tourner des astuces, tirez un nombre avec random (1.20.2 et plus) et choisissez une ligne :

execute store result score #tip announce run random value 1..3
execute if score #tip announce matches 1 run tellraw @a {"text":"Astuce : le marché du spawn ouvre chaque soir","color":"gray"}
execute if score #tip announce matches 2 run tellraw @a {"text":"Astuce : le règlement est affiché au spawn","color":"gray"}
execute if score #tip announce matches 3 run tellraw @a {"text":"Astuce : le prochain événement a lieu samedi","color":"gray"}
schedule function cube:broadcast 6000t

Créez le score une seule fois avec scoreboard objectives add announce dummy. Le générateur de data pack crée le dossier et le pack.mcmeta pour votre version.

Rester lisible

La couleur doit aider à trier le message, pas le décorer : rouge pour le danger, or pour la voix du serveur, cyan pour les objectifs, gris pour le secondaire. Infobulles et liens sont des extras ; personne ne s'arrête pour les lire en plein événement, alors n'y cachez jamais l'essentiel. Si le message demande des détails, mettez le titre à l'écran et les détails dans le chat.

FAQ

Comment envoyer une annonce depuis la console du serveur ?

Tapez la commande sans barre oblique : say … ou tellraw @a …. La console a tous les droits, donc chaque commande de cette page y fonctionne.

Pourquoi mon lien cliquable ne fait rien ?

En 1.21.5 et plus, les champs s'appellent click_event et url ; clickEvent et value des anciens guides sont ignorés. Vérifiez aussi que les liens web sont activés dans les paramètres du chat du joueur.

Peut-on annoncer à une partie des joueurs seulement ?

Changez le sélecteur : @a[team=red] pour une équipe, @a[distance=..50] pour les joueurs proches d'un bloc de commande, ou execute in minecraft:the_nether run tellraw @a[distance=0..] … pour tous ceux qui sont dans le Nether.

Les plugins font-ils mieux ?

Des plugins comme EssentialsX ajoutent /broadcast et des listes de messages automatiques. Les commandes vanilla de cette page marchent aussi sur Paper et Spigot, sans rien installer.
