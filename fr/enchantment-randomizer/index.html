Randomiseur d'enchantements et d'attributs

Choisissez un objet, tirez un ensemble aléatoire d'enchantements vanilla et de modificateurs d'attributs, puis récupérez soit une commande /give prête, soit une entrée de table de butin — avec les plages conservées comme number providers, pour que le jeu tire lui-même la valeur exacte à chaque butin plutôt que vous, une seule fois ici.

Lire le guide Incompatibilités d'enchantements

Le jeu vanilla impose des groupes d'enchantements mutuellement exclusifs (protection, dégâts, fortune/toucher de soie, etc.). Cet outil les respecte par défaut — liste complète dans le guide.

Deux formats de sortie, deux usages

La commande /give tire un objet concret, tout de suite — à coller dans un bloc de commande ou le chat. L'entrée de table de butin conserve les plages comme number providers minecraft:uniform, donc chaque butin de cette table tire sa propre valeur en jeu au lieu de toujours reproduire cette instance.

Pourquoi certaines combinaisons n'apparaissent jamais

Le jeu vanilla regroupe certains enchantements comme mutuellement exclusifs — vous ne verrez jamais Tranchant et Aubaine sur la même épée, ni Protection et Protection contre le feu sur le même casque. "Respecter les incompatibilités vanilla" applique les mêmes groupes ici ; désactivez-le uniquement pour un data pack qui modifie volontairement la compatibilité.
