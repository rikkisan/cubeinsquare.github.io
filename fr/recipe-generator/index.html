Générateur de recettes Minecraft

Les recettes sont des fichiers de data pack, pas des commandes : cet outil vous donne donc le JSON et le chemin où il va. Disposez une recette sur une grille 3×3 et le motif et les clés sont déduits pour vous — y compris le rognage des lignes vides, l’étape que tout le monde oublie.

Lire le guide Générateur de data packs

Le fichier de recette vit dans un data pack. Si vous n’en avez pas encore, le générateur de data packs crée le dossier.

Comment utiliser le fichier

  1. Enregistrez le JSON au chemin indiqué, dans votre data pack.
  2. Lancez /reload.
  3. Ouvrez un établi et essayez.

Une nouvelle recette doit encore être débloquée pour apparaître dans le livre de recettes. Elle fonctionne dans la grille dans tous les cas.

Le format a changé deux fois

1.20.5 a renommé le champ item du résultat en id. 1.21.2 a permis d’écrire les ingrédients comme de simples identifiants au lieu de {"item": id}. Une recette copiée d’un ancien tutoriel échoue sur un jeu récent et inversement — le sélecteur de version ci-dessus réécrit donc la forme pour vous.

Utiliser le générateur

Choisissez un type de recette et une version, remplissez la grille ou la liste d’ingrédients, puis copiez ou téléchargez le JSON avec son chemin.

Type et version

Recettes avec ou sans forme, quatre types de cuisson et tailleur de pierre ont chacun leurs champs ; la version décide de la forme du JSON écrit.

Catégorie

L’onglet du livre de recettes où elle apparaît. L’artisanat utilise building, redstone, equipment et misc ; la cuisson food, blocks et misc. Le tailleur de pierre n’en a pas.

La grille

Tapez un identifiant dans chaque case utile. Les rangées et colonnes vides du bord sont retirées : un motif qui tient en 2×2 marche aussi dans la grille de l’inventaire. Le préfixe # désigne un tag d’objets, comme #minecraft:planks.

Résultat, expérience, durée

Réglez l’objet produit et sa quantité. Les recettes de cuisson ajoutent l’expérience et une durée en ticks : 200 (10 secondes) pour les recettes de four vanilla, la moitié pour le haut fourneau et le fumoir.

Pourquoi une recette semble absente

Absente du livre

Une nouvelle recette marche tout de suite dans la grille, mais n’apparaît dans le livre qu’une fois débloquée : /recipe give @s harbor:reinforced_block, ou un progrès qui la donne en récompense.

Copiée d’un vieux tutoriel

La 1.20.5 a renommé le champ du résultat de item en id, et la 1.21.2 a permis des identifiants simples comme ingrédients. Un fichier à la mauvaise forme échoue sans erreur visible en jeu.

Modifier une recette vanilla

Un fichier portant le nom vanilla dans l’espace minecraft, comme data/minecraft/recipe/torch.json, remplace la recette d’origine.

Versions

Java Edition 1.20 à 26.3. La forme du JSON change en 1.20.5 et en 1.21.2, et le dossier s’appelle recipe depuis la 1.21 et recipes avant ; le générateur suit la version choisie.
