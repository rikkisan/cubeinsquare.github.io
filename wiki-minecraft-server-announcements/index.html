How to make announcements on a Minecraft server

Vanilla Minecraft has five ways to tell every player something at once: a chat line with /say, a formatted message with /tellraw, big screen text with /title, a line above the hotbar, and a boss bar. All of them run from the server console, a command block or a data pack function, with no plugins. Below are the commands for 1.21.5 – 26.x, what differs in older versions, and how to repeat a message on a timer.

Pick the channel first

Where the message appears decides how players take it. Chat stays in history, screen text interrupts, and a bar sits there until you remove it.

CommandWhere players see itUse it for
/sayChat, as a [Server] line or with your nameA quick note typed into the console
/tellrawChat, with colors, hover text and linksRules, links, anything players may scroll back to
/title … titleLarge text in the middle of the screenRare big moments: an event starts, a verdict
/title … actionbarOne line above the hotbarTimers, warnings, short feedback
/bossbarA bar across the top of the screenEvents that last minutes, shared countdowns

/say: the fastest way

In the server console type commands without the slash; in chat or a command block, with it:

say Server restarts in 10 minutes

From the console players see [Server] Server restarts in 10 minutes. From a player the line carries their name, and from a command block the block's name (@ unless you renamed it). /say takes no colors, and a selector such as @a inside the text turns into player names.

/tellraw: colors, hover text and links

/tellraw sends a text component to the players you select. With quoted keys the same command works on every version from 1.20 to 26.x, because it is valid JSON for the older versions and valid SNBT for 1.21.5 and newer:

tellraw @a {"text":"Server restarts in 10 minutes","color":"gold","bold":true}

Parts with different styles go in a list:

tellraw @a [{"text":"[Event] ","color":"red"},{"text":"The arena opens at 18:00","color":"white"}]

Hover text and clickable links are where versions split. 1.21.5 renamed the fields, so a command copied from an older guide shows its text but does nothing on hover or click:

1.21.5 – 26.x

tellraw @a {"text":"Read the rules","color":"aqua","underlined":true,"hover_event":{"action":"show_text","value":"Opens the rules page"},"click_event":{"action":"open_url","url":"https://example.com/rules"}}

1.20 – 1.21.4

tellraw @a {"text":"Read the rules","color":"aqua","underlined":true,"hoverEvent":{"action":"show_text","contents":"Opens the rules page"},"clickEvent":{"action":"open_url","value":"https://example.com/rules"}}

The other click actions changed the same way: from 1.21.5, run_command and suggest_command take command instead of value. Players confirm a link before it opens, and nothing opens for a player who turned web links off in the chat settings.

/title: big text, subtitles and the action bar

A title takes three steps: timing, then the subtitle, then the title. The subtitle waits until a title arrives, so send it first:

title @a times 10 70 20
title @a subtitle {"text":"The arena opens in one minute","color":"gray"}
title @a title {"text":"EVENT","color":"gold","bold":true}

The numbers are fade in, stay and fade out in ticks (20 ticks are one second), so this title shows for about five seconds. Keep it to a word or two: players read it while moving. The action bar is a quieter line above the hotbar:

title @a actionbar {"text":"PvP is off until 18:00","color":"green"}

It fades after a few seconds. To keep a line up, for a timer or a warning, send it again every second from a function like the one below. title @a clear removes what is on screen, and title @a reset also resets the timing.

Boss bars for events that last

A boss bar stays at the top of the screen until you remove it, which suits events and countdowns:

bossbar add cube:event {"text":"Siege of the north gate"}
bossbar set cube:event color red
bossbar set cube:event players @a
bossbar remove cube:event

The bossbar builder writes the full set with value and style, and bossbars for events shows a working countdown.

Repeat a message on a timer

A data pack function can run itself again later with /schedule. Save this as data/cube/function/broadcast.mcfunction (the folder is functions before 1.21):

tellraw @a {"text":"Next event: Saturday, 18:00 at the arena","color":"gray"}
schedule function cube:broadcast 6000t

Run function cube:broadcast once and it repeats every 6000 ticks, five minutes at 20 ticks per second; schedule clear cube:broadcast stops it. For rotating tips, roll a number with random (1.20.2 and newer) and pick a line:

execute store result score #tip announce run random value 1..3
execute if score #tip announce matches 1 run tellraw @a {"text":"Tip: the market at spawn opens every evening","color":"gray"}
execute if score #tip announce matches 2 run tellraw @a {"text":"Tip: read the rules on the board at spawn","color":"gray"}
execute if score #tip announce matches 3 run tellraw @a {"text":"Tip: the next event starts on Saturday","color":"gray"}
schedule function cube:broadcast 6000t

Create the score once with scoreboard objectives add announce dummy. The data pack generator builds the folder and pack.mcmeta for your version.

Keep it readable

Color should help players sort the message, not decorate it: red for danger, gold for the server's voice, aqua for objectives, gray for side notes. Hover text and links are extras; nobody stops to inspect them in the middle of an event, so never hide the essential part there. When a message needs detail, put the headline on screen and the details in chat.

FAQ

How do I send an announcement from the server console?

Type the command without the slash: say … or tellraw @a …. The console has full permissions, so every command on this page works there.

Why does my clickable link do nothing?

On 1.21.5 and newer the fields are click_event and url; clickEvent and value from older guides are ignored. Also check that web links are on in the player's chat settings.

Can I announce to only some players?

Change the selector: @a[team=red] for one team, @a[distance=..50] for players near a command block, or execute in minecraft:the_nether run tellraw @a[distance=0..] … for everyone in the Nether.

Do plugins do this better?

Plugins such as EssentialsX add /broadcast and automatic message lists. The vanilla commands here also work on Paper and Spigot, and nothing has to be installed.
