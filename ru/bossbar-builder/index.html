Генератор bossbar для Minecraft

Создавайте наборы команд bossbar для ролевых событий, рейдов, ритуалов, отсчётов и общих предупреждений сервера. Выберите ID, заголовок, цвет, стиль, игроков и прогресс, а затем скопируйте чистую последовательность для командных блоков или datapack-функций.

Быстрые пресеты

Настройка bossbar

Bossbar лучше всего работает как состояние: опасность, заряд ритуала, фаза боя, время эвакуации или общее давление на сервере. Этот инструмент создаёт команды настройки; живой таймер всё равно нужно обновлять через повторяющийся командный блок или datapack-функцию.

Готовые команды

Bossbar

  • /bossbar add
  • /bossbar set value
  • /bossbar set players
  • /bossbar remove

Как пользоваться генератором

Генератор пишет семь команд /bossbar: одна создаёт шкалу, шесть настраивают её. Превью показывает заголовок, цвет и заполнение ещё до копирования.

Начните с пресета

Ritual charge, Raid phase II, Evacuation: 3 minutes и Phase break incoming заполняют все поля под типичное событие. Перед использованием смените ID, чтобы два события не делили одну шкалу.

Два имени

ID, например cube:ritual_charge, — то, по чему шкалу найдут следующие команды; он пишется строчными, а без пространства имён получит cube:. Заголовок — то, что читают игроки; он мелко написан над шкалой, так что хватит пары слов.

Цвет и стиль

Для таймеров и всего непрерывного берите progress, а стиль с делениями — когда игрокам нужно считать фазы. Число делений должно делиться на ваш максимум без остатка.

Максимум, значение и игроки

У max и value одна единица: секунды, фазы, подношения. Players решает, кто видит шкалу прямо сейчас; кто зайдёт позже, ничего не увидит, пока строку не выполнят снова.

Скопировать и запустить

Вставляйте строки в чат по одной для проверки, в командные блоки — по строке на блок, в файл функции — без начального слэша.

Три вещи, которые команды за вас не сделают

Повторный запуск

Строка add падает, если такой ID уже есть. Чтобы пересоздать шкалу, сначала выполните /bossbar remove или пропустите первую строку.

Обратный отсчёт

Шкала показывает последнее значение, которое ей дали. Таймеру нужен цикл, который её обновляет; рабочий отсчёт разобран в статье о событиях.

Уборка

Свои шкалы сохраняются в мире и переживают перезапуск. В конце сцены выполните /bossbar remove, а /bossbar list покажет забытые.

Версии

Java Edition 1.13–26.3. Заголовок записан как {"text":"…","color":"white"}: до 1.21.4 игра читает его как JSON, с 1.21.5 — как SNBT, поэтому одни и те же строки работают в обеих. В Bedrock Edition команды /bossbar нет.
