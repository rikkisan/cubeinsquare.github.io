Как делать объявления на сервере Minecraft

В ванильном Minecraft пять способов сообщить что-то всем игрокам сразу: строка в чате через /say, оформленное сообщение через /tellraw, крупный текст на экране через /title, строка над хотбаром и боссбар. Все они работают из консоли сервера, командного блока или функции датапака, без плагинов. Ниже команды для 1.21.5 – 26.x, отличия старых версий и способ повторять сообщение по таймеру.

Сначала выберите канал

То, где появляется сообщение, решает, как его воспримут. Чат остаётся в истории, текст на экране прерывает игру, а полоса висит, пока вы её не уберёте.

/say: самый быстрый способ

В консоли сервера команды пишутся без слэша, в чате и командном блоке — со слэшем:

say Сервер перезапустится через 10 минут

Из консоли игроки увидят [Server] Сервер перезапустится через 10 минут. От игрока строка придёт с его ником, от командного блока — с именем блока (@, если вы его не переименовали). Цветов /say не понимает, а селектор вроде @a в тексте превращается в список ников.

/tellraw: цвета, подсказки и ссылки

/tellraw отправляет текстовый компонент выбранным игрокам. С ключами в кавычках одна и та же команда работает во всех версиях от 1.20 до 26.x: для старых версий это правильный JSON, для 1.21.5 и новее — правильный SNBT:

tellraw @a {"text":"Сервер перезапустится через 10 минут","color":"gold","bold":true}

Части с разным оформлением записываются списком:

tellraw @a [{"text":"[Событие] ","color":"red"},{"text":"Арена откроется в 18:00","color":"white"}]

Подсказки при наведении и кликабельные ссылки — то место, где версии расходятся. В 1.21.5 поля переименовали, поэтому команда из старого гайда показывает текст, но на наведение и клик не реагирует:

1.21.5 – 26.x

tellraw @a {"text":"Прочитать правила","color":"aqua","underlined":true,"hover_event":{"action":"show_text","value":"Откроет страницу с правилами"},"click_event":{"action":"open_url","url":"https://example.com/rules"}}

1.20 – 1.21.4

tellraw @a {"text":"Прочитать правила","color":"aqua","underlined":true,"hoverEvent":{"action":"show_text","contents":"Откроет страницу с правилами"},"clickEvent":{"action":"open_url","value":"https://example.com/rules"}}

Остальные действия по клику изменились так же: с 1.21.5 run_command и suggest_command берут command вместо value. Перед открытием ссылки игрок подтверждает переход, а у того, кто выключил веб-ссылки в настройках чата, ничего не откроется.

/title: крупный текст, подзаголовок и строка над хотбаром

Заголовок задаётся в три шага: тайминг, подзаголовок, сам заголовок. Подзаголовок ждёт, пока придёт заголовок, поэтому его отправляют первым:

title @a times 10 70 20
title @a subtitle {"text":"Арена откроется через минуту","color":"gray"}
title @a title {"text":"СОБЫТИЕ","color":"gold","bold":true}

Числа — это появление, показ и исчезание в тиках (20 тиков — одна секунда), так что этот заголовок висит около пяти секунд. Оставляйте в нём слово-два: игрок читает его на бегу. Строка над хотбаром (action bar) звучит тише:

title @a actionbar {"text":"PvP выключен до 18:00","color":"green"}

Она гаснет через несколько секунд. Чтобы строка держалась, например для таймера или предупреждения, отправляйте её заново каждую секунду из функции вроде той, что ниже. title @a clear убирает текст с экрана, а title @a reset ещё и сбрасывает тайминг.

Боссбары для долгих событий

Боссбар держится вверху экрана, пока вы его не удалите, поэтому он хорош для событий и отсчётов:

bossbar add cube:event {"text":"Осада северных ворот"}
bossbar set cube:event color red
bossbar set cube:event players @a
bossbar remove cube:event

Конструктор боссбаров соберёт полный набор команд со значением и стилем, а статья о боссбарах для событий показывает рабочий обратный отсчёт.

Повтор сообщения по таймеру

Функция датапака может запустить сама себя позже через /schedule. Сохраните это как data/cube/function/broadcast.mcfunction (до 1.21 папка называется functions):

tellraw @a {"text":"Следующее событие: суббота, 18:00 на арене","color":"gray"}
schedule function cube:broadcast 6000t

Выполните function cube:broadcast один раз, и сообщение будет повторяться каждые 6000 тиков, то есть каждые пять минут при 20 тиках в секунду. Остановит его schedule clear cube:broadcast. Чтобы подсказки менялись, бросьте число через random (1.20.2 и новее) и выберите строку:

execute store result score #tip announce run random value 1..3
execute if score #tip announce matches 1 run tellraw @a {"text":"Совет: рынок на спавне открывается каждый вечер","color":"gray"}
execute if score #tip announce matches 2 run tellraw @a {"text":"Совет: правила висят на доске у спавна","color":"gray"}
execute if score #tip announce matches 3 run tellraw @a {"text":"Совет: следующее событие в субботу","color":"gray"}
schedule function cube:broadcast 6000t

Счёт создаётся один раз: scoreboard objectives add announce dummy. Генератор датапаков соберёт папку и pack.mcmeta под вашу версию.

Чтобы объявление читали

Цвет должен помогать разобрать сообщение, а не украшать его: красный — опасность, золотой — голос сервера, бирюзовый — цели, серый — второстепенное. Подсказки и ссылки — дополнение: посреди события их никто не изучает, так что главное в них не прячьте. Если нужны подробности, выведите заголовок на экран, а детали — в чат.

Часто задаваемые вопросы

Как отправить объявление из консоли сервера?

Напишите команду без слэша: say … или tellraw @a …. У консоли полные права, так что там работает любая команда с этой страницы.

Почему моя ссылка не кликается?

В 1.21.5 и новее поля называются click_event и url; clickEvent и value из старых гайдов игнорируются. Проверьте ещё, что у игрока включены веб-ссылки в настройках чата.

Можно ли написать только части игроков?

Поменяйте селектор: @a[team=red] для одной команды, @a[distance=..50] для игроков рядом с командным блоком или execute in minecraft:the_nether run tellraw @a[distance=0..] … для всех, кто в Незере.

Плагины делают это лучше?

Плагины вроде EssentialsX добавляют /broadcast и автоматические списки сообщений. Ванильные команды с этой страницы работают и на Paper, и на Spigot, и ставить ничего не нужно.
