Minecraft Tools, Resource Pack Generator and Wiki

Eighteen browser tools for Minecraft Java creators and server admins. Each one gives you something to paste or drop into the game: a command, a JSON file, a ZIP pack or a PNG. Commands and data pack files follow the syntax of the version you choose, and every tool has a guide in the wiki that explains its output.

The tools were first written for Cube in Square, a mod-free roleplay server. Its second season has ended and the third is in development.

Every entry says what the tool gives you. The guide link explains that output and where it goes.

Items, potions and traders

Commands that hand players something new.

  • Custom item builder: a /give command with name, lore, model and a hidden ID, in the syntax of your version (guide)
  • Custom potions: potions, splash and lingering potions with your own effects, colour and name (guide)
  • Custom villager trades: a /summon command for a villager with your own trades, prices and limits (guide)
  • Enchantment & attribute randomizer: a random set of enchantments and attribute modifiers for loot and rewards (guide)

Text players read

Books, NPC lines and on-screen events.

  • Book & letter builder: written books, letters and notes as a /give command, page by page (guide)
  • Dialogue builder: NPC lines, narration, action bar and title messages as tellraw and title commands (guide)
  • Bossbar builder: boss bar commands for events, phases and countdowns (guide)

Data pack files

The JSON files of a data pack, and the pack around them.

  • Data pack generator: the pack folder and pack.mcmeta with the right format for your version (guide)
  • Loot table generator: chest loot, mob drops and fishing tables with pools, weights and chances (guide)
  • Recipe generator: crafting recipes laid out on a grid and saved as JSON (guide)
  • Advancement builder: quest chains and recipe unlocks as advancement files (guide)

Resource packs and models

How custom items look, and keeping track of them.

  • Resource pack generator: a ZIP pack with your item and block textures in the right folders (guide)
  • Item model builder: the item definition files that 1.21.4 and newer read from assets/<namespace>/items/ (guide)
  • Custom item catalog: one list of your server’s custom items, their IDs, base items and models (guide)

Skins and textures

Draw the PNG files themselves.

  • Skin editor: a 64×64 player skin, painted on the atlas or on the 3D model (guide)
  • Texture painter: item and block textures from 16×16 to 128×128, ready for a pack (guide)

Build planning

Layer-by-layer plans before you place a block.

  • Sphere generator: solid and hollow spheres and domes, layer by layer (guide)
  • Circle & dome planner: circles, thick rings, arches and dome profiles (guide)

Frequently asked questions

Do I need mods to use these tools?

No. The tools write vanilla commands, data pack files, resource packs and PNG files. The only mods on this site are two optional client mods of ours, ArmorHide and Chest Helper.

Which Minecraft versions do the tools cover?

Java Edition. The command and data pack tools ask for your version and write the matching syntax, from NBT before 1.20.5 to the components of 1.21.5 and 26.x, and each page says what changed between them. The resource pack generator writes 1.20-format packs; its page explains what that means on newer versions.

Are my files uploaded?

No. Drawing, pack building and command generation run in your browser, and your PNG files and ZIP packs stay on your device.

A command from here does not work. What now?

Check the version first: most broken commands were written for a different one. This guide shows the same command for each version and the errors that come from mixing them. If a tool’s output is wrong for your version, write to cubeinsquare@proton.me with the version and the command.
