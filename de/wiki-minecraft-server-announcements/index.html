Ankündigungen auf einem Minecraft-Server machen

Vanilla-Minecraft hat fünf Wege, allen Spielern gleichzeitig etwas zu sagen: eine Chatzeile mit /say, eine formatierte Nachricht mit /tellraw, großen Text auf dem Bildschirm mit /title, eine Zeile über der Schnellleiste und eine Bossleiste. Alle laufen aus der Serverkonsole, einem Befehlsblock oder einer Datenpaket-Funktion, ganz ohne Plugins. Unten findest du die Befehle für 1.21.5 – 26.x, die Unterschiede älterer Versionen und eine Nachricht, die sich nach Zeitplan wiederholt.

Erst den Kanal wählen

Wo die Nachricht erscheint, entscheidet, wie Spieler sie aufnehmen. Der Chat bleibt im Verlauf, Bildschirmtext unterbricht, und eine Leiste bleibt stehen, bis du sie entfernst.

BefehlWo Spieler es sehenWofür
/sayIm Chat, als [Server]-Zeile oder mit deinem NamenEine schnelle Notiz aus der Konsole
/tellrawIm Chat, mit Farben, Hover-Text und LinksRegeln, Links, alles, was man im Verlauf nachliest
/title … titleGroßer Text in der BildschirmmitteSeltene große Momente: Eventstart, Urteil

/say: der schnellste Weg

In der Serverkonsole tippst du Befehle ohne Schrägstrich, im Chat oder Befehlsblock mit:

say Server startet in 10 Minuten neu

Aus der Konsole sehen Spieler [Server] Server startet in 10 Minuten neu. Von einem Spieler trägt die Zeile seinen Namen, von einem Befehlsblock dessen Namen (@, solange du ihn nicht umbenennst). /say kennt keine Farben, und ein Selektor wie @a im Text wird zu einer Liste von Spielernamen.

/tellraw: Farben, Hover-Text und Links

/tellraw schickt einen Textbaustein an die gewählten Spieler. Mit Schlüsseln in Anführungszeichen läuft derselbe Befehl in jeder Version von 1.20 bis 26.x: Für ältere Versionen ist er gültiges JSON, ab 1.21.5 gültiges SNBT:

tellraw @a {"text":"Server startet in 10 Minuten neu","color":"gold","bold":true}

Teile mit unterschiedlichem Stil kommen in eine Liste:

tellraw @a [{"text":"[Event] ","color":"red"},{"text":"Die Arena öffnet um 18 Uhr","color":"white"}]

Bei Hover-Text und klickbaren Links trennen sich die Versionen. 1.21.5 hat die Felder umbenannt, deshalb zeigt ein Befehl aus einer älteren Anleitung zwar den Text, reagiert aber weder auf Hover noch auf Klick:

1.21.5 – 26.x

tellraw @a {"text":"Regeln lesen","color":"aqua","underlined":true,"hover_event":{"action":"show_text","value":"Öffnet die Regelseite"},"click_event":{"action":"open_url","url":"https://example.com/rules"}}

1.20 – 1.21.4

tellraw @a {"text":"Regeln lesen","color":"aqua","underlined":true,"hoverEvent":{"action":"show_text","contents":"Öffnet die Regelseite"},"clickEvent":{"action":"open_url","value":"https://example.com/rules"}}

Die anderen Klick-Aktionen haben sich genauso geändert: Ab 1.21.5 nehmen run_command und suggest_command das Feld command statt value. Spieler bestätigen einen Link, bevor er sich öffnet, und wer Weblinks in den Chateinstellungen ausgeschaltet hat, bekommt gar nichts geöffnet.

/title: großer Text, Untertitel und Aktionsleiste

Ein Titel braucht drei Schritte: Timing, dann den Untertitel, dann den Titel. Der Untertitel wartet auf einen Titel, also schickst du ihn zuerst:

title @a times 10 70 20
title @a subtitle {"text":"Die Arena öffnet in einer Minute","color":"gray"}
title @a title {"text":"EVENT","color":"gold","bold":true}

Die Zahlen sind Einblenden, Anzeigen und Ausblenden in Ticks (20 Ticks sind eine Sekunde), dieser Titel steht also etwa fünf Sekunden. Halte ihn bei ein, zwei Wörtern, denn Spieler lesen ihn in Bewegung. Die Aktionsleiste ist eine ruhigere Zeile über der Schnellleiste:

title @a actionbar {"text":"PvP ist bis 18 Uhr aus","color":"green"}

Sie verblasst nach ein paar Sekunden. Soll eine Zeile stehen bleiben, etwa für einen Timer oder eine Warnung, schick sie jede Sekunde neu aus einer Funktion wie der unten. title @a clear räumt den Bildschirm, title @a reset setzt zusätzlich das Timing zurück.

Bossleisten für längere Events

Eine Bossleiste bleibt oben auf dem Bildschirm, bis du sie entfernst. Das passt zu Events und Countdowns:

bossbar add cube:event {"text":"Belagerung des Nordtors"}
bossbar set cube:event color red
bossbar set cube:event players @a
bossbar remove cube:event

Der Bossbar-Generator schreibt den kompletten Satz mit Wert und Stil, und der Artikel über Bossleisten für Events zeigt einen funktionierenden Countdown.

Eine Nachricht nach Zeitplan wiederholen

Eine Datenpaket-Funktion kann sich mit /schedule später selbst wieder starten. Speichere das als data/cube/function/broadcast.mcfunction (vor 1.21 heißt der Ordner functions):

tellraw @a {"text":"Nächstes Event: Samstag, 18 Uhr in der Arena","color":"gray"}
schedule function cube:broadcast 6000t

Führe function cube:broadcast einmal aus, dann wiederholt sich die Nachricht alle 6000 Ticks, also alle fünf Minuten bei 20 Ticks pro Sekunde; schedule clear cube:broadcast stoppt sie. Für wechselnde Tipps würfelst du mit random (ab 1.20.2) eine Zahl und wählst eine Zeile:

execute store result score #tip announce run random value 1..3
execute if score #tip announce matches 1 run tellraw @a {"text":"Tipp: Der Markt am Spawn öffnet jeden Abend","color":"gray"}
execute if score #tip announce matches 2 run tellraw @a {"text":"Tipp: Die Regeln hängen am Brett beim Spawn","color":"gray"}
execute if score #tip announce matches 3 run tellraw @a {"text":"Tipp: Das nächste Event ist am Samstag","color":"gray"}
schedule function cube:broadcast 6000t

Lege den Punktestand einmal an mit scoreboard objectives add announce dummy. Der Datenpaket-Generator baut den Ordner und die pack.mcmeta für deine Version.

Lesbar bleiben

Farbe soll beim Einordnen helfen, nicht schmücken: Rot für Gefahr, Gold für die Stimme des Servers, Türkis für Ziele, Grau für Nebensachen. Hover-Text und Links sind Extras; mitten im Event hält niemand an, um sie zu lesen, also versteck dort nie das Wichtige. Braucht eine Nachricht Details, kommt die Überschrift auf den Bildschirm und der Rest in den Chat.

NachrichtKanalWarum es funktioniert
Neustart-WarnungAktionsleiste + tellrawDie Aktionsleiste hält den Druck sichtbar, tellraw hinterlässt einen Eintrag.
Quest abgeschlossenAktionsleisteKurzes Feedback muss den Chat nicht füllen.
Ritual beginnttitle + subtitleDer Moment soll gewichtig und gemeinsam wirken.
Gerichtsurteiltitle, dann tellrawDer Titel verkündet das Urteil, der Chat behält den genauen Wortlaut.

FAQ

Wie sende ich eine Ankündigung aus der Serverkonsole?

Tippe den Befehl ohne Schrägstrich: say … oder tellraw @a …. Die Konsole hat alle Rechte, also funktioniert dort jeder Befehl von dieser Seite.

Warum passiert bei meinem Link nichts?

Ab 1.21.5 heißen die Felder click_event und url; clickEvent und value aus älteren Anleitungen werden ignoriert. Prüfe auch, ob Weblinks in den Chateinstellungen des Spielers an sind.

Kann ich nur einem Teil der Spieler etwas ankündigen?

Ändere den Selektor: @a[team=red] für ein Team, @a[distance=..50] für Spieler in der Nähe eines Befehlsblocks oder execute in minecraft:the_nether run tellraw @a[distance=0..] … für alle im Nether.

Machen Plugins das besser?

Plugins wie EssentialsX bringen /broadcast und automatische Nachrichtenlisten mit. Die Vanilla-Befehle hier laufen auch auf Paper und Spigot, und installieren musst du nichts.
