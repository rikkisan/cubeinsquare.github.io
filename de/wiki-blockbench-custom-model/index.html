Vom Blockbench-Modell zum Item im Spiel: Export, Pack-Pfade und Einbindung

Blockbench baut das Modell, das Resource Pack entscheidet, welches Item es zeigt. Die Modelldatei ist seit 1.13 in jeder Version gleich, aber wie man einem Item sagt, welches Modell es nutzen soll, hat sich in 1.21.4 geändert – der letzte Schritt hängt also von deiner Version ab.

item_model-BuilderStruktur eines Resource Packs

Geprüft für die Versionen: Java Edition 1.20 bis 26.3. Die Bedrock-Formate von Blockbench funktionieren in der Java Edition nicht.

In Blockbench

  • Nimm das Format „Java Block/Item“. Es setzt die Regeln des Spiels durch: Jeder Würfel muss auf jeder Achse zwischen −16 und 32 bleiben (drei Blöcke), und ein Würfel dreht sich nur um eine Achse, in Schritten von 22,5° bis 45°, die jede Version annimmt.
  • Die Anzeige einstellen. Der Reiter Display bestimmt, wie das Modell in der Hand, auf dem Kopf, im Rahmen und im Inventar sitzt. Ohne ihn füllt ein großes Modell den Schnellleisten-Slot oder schwebt neben der Hand.
  • Texturen nach ihrem Pack-Pfad benennen. Eine als assets/cube/textures/item/guild_hammer.png gespeicherte Textur wird als cube:item/guild_hammer referenziert. Blockbench schreibt diese Referenz ins Modell, der Pfad muss also schon beim Export stimmen.
  • Exportieren über File → Export → Export Block/Item Model nach assets/cube/models/item/.

Wohin die Dateien gehören

my_pack/
  pack.mcmeta
  assets/cube/
    items/guild_hammer.json          (1.21.4+ only)
    models/item/guild_hammer.json    (exported from Blockbench)
    textures/item/guild_hammer.png

Nutz für neue Dateien deinen eigenen Namensraum (hier cube) statt minecraft, damit sie nicht mit Vanilla-Ressourcen oder einem anderen Pack kollidieren.

Einbinden ab 1.21.4

Eine Item-Definition in items/ sagt, welches Modell gezeichnet wird:

{
  "model": {
    "type": "minecraft:model",
    "model": "cube:item/guild_hammer"
  }
}

Das Item zeigt mit der Komponente item_model auf diese Datei, in 1.21.4 und 1.21.5 – 26.x gleich geschrieben:

/give @p minecraft:stick[minecraft:item_model="cube:guild_hammer"] 1

Ein Modell kann mehrere Zustände eines Items bedienen (geladen, zerbrochen, Fraktionsfarben) über select, range_dispatch oder condition in der Definition; diese Dateien schreibt der item_model-Builder.

Einbinden bis 1.21.3

Ältere Versionen haben keinen Ordner items/. Stattdessen bekommt das Modell des Vanilla-Items einen Override, der nach CustomModelData umschaltet, in assets/minecraft/models/item/stick.json:

{
  "parent": "minecraft:item/handheld",
  "textures": { "layer0": "minecraft:item/stick" },
  "overrides": [
    { "predicate": { "custom_model_data": 1 }, "model": "cube:item/guild_hammer" }
  ]
}

Der Befehl setzt dann die Zahl, mit Komponenten in 1.20.5 – 1.21.3 oder mit NBT davor:

/give @p minecraft:stick[minecraft:custom_model_data=1] 1
/give @p minecraft:stick{CustomModelData:1} 1

Ab 1.21.4 werden Overrides ignoriert – der häufigste Grund, warum ein Pack, das „letztes Jahr lief“, nur noch Vanilla-Items zeigt.

Wenn nichts erscheint

  • Lila-schwarzes Schachbrett auf dem Modell: Das Modell wurde geladen, die Textur nicht. Vergleich die Texturreferenz im Modell-JSON mit dem echten Pfad der PNG.
  • Lila-schwarzer Würfel statt des Modells: Die Modelldatei wurde nicht gefunden oder nicht geladen. Prüf den Pfad in der Item-Definition oder im Override und such den Dateinamen im Spiel-Log.
  • Riesig oder falsch in der Hand: Die Display-Einstellungen stehen noch auf Standard.
  • Nach einer Änderung passiert nichts: Drück im Spiel F3+T, um die Resource Packs neu zu laden; ein Neustart ist nicht nötig.
  • Pack als inkompatibel markiert: pack.mcmeta nennt das Format einer anderen Version. Die Seite „Pack format“ im Minecraft Wiki listet die Nummer für jedes Release.

Häufige Fragen

Kann ein Modell von mehreren Items genutzt werden?

Ja. Mehrere Item-Definitionen oder mehrere Overrides können auf dieselbe Modelldatei zeigen.

Kann die Textur animiert sein?

Ja, mit einem senkrechten Streifen von Einzelbildern in der PNG und einer .png.mcmeta-Datei daneben, die die Bilddauer festlegt.

Welches Basisitem soll das Modell tragen?

Eins, dessen Verhalten passt: Stock oder Karottenrute für Requisiten, Schwert oder Axt für Waffen, Papier für Dokumente. Das Modell ändert nur das Aussehen.
