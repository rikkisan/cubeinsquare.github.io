Minecraft Bossbar-Builder

Baue Bossbar-Befehlsstapel für RP-Events, Raids, Rituale, Countdowns und serverweite Warnungen. Wähle ID, Titel, Farbe, Stil, Spieler und Fortschritt und kopiere danach eine saubere Sequenz für Command-Blöcke oder Datapack-Funktionen.

Leitfaden lesenArtikel zu Event-UI

Schnellvorlagen

Bossbar-Setup

Bossbars sind am stärksten, wenn sie Zustand zeigen: Gefahr, Ritual-Ladung, Phase, Evakuierungszeit oder öffentlichen Serverdruck. Dieses Werkzeug erzeugt Setup-Befehle; ein laufender Timer muss weiter über wiederholende Command-Blöcke oder Datapack-Funktionen aktualisiert werden.

Erzeugte Befehle

Bossbar

  • /bossbar add
  • /bossbar set value
  • /bossbar set players
  • /bossbar remove

So benutzt du den Builder

Der Builder schreibt sieben /bossbar-Befehle: einer erstellt die Leiste, sechs richten sie ein. Die Vorschau zeigt Titel, Farbe und Füllstand, bevor du etwas kopierst.

Mit einer Vorlage starten

Ritual charge, Raid phase II, Evacuation: 3 minutes und Phase break incoming füllen alle Felder für ein typisches Event. Ändere die ID, bevor du eine nutzt, damit sich nie zwei Events eine Leiste teilen.

Zwei Namen

Die ID, etwa cube:ritual_charge, ist das, woran spätere Befehle die Leiste finden; sie ist kleingeschrieben und bekommt den Namensraum cube:, wenn du keinen angibst. Der Titel ist das, was Spieler lesen, klein über der Leiste – ein paar Wörter reichen.

Farbe und Stil

progress für Timer und alles Fließende, ein gekerbter Stil, wenn Spieler Phasen mitzählen sollen. Wähl eine Kerbenzahl, durch die sich dein Maximum glatt teilen lässt.

Max, Wert und Spieler

Max und value haben dieselbe Einheit: Sekunden, Phasen, Opfergaben. Players legt fest, wer die Leiste gerade sieht; wer später einloggt, sieht nichts, bis die Zeile erneut läuft.

Kopieren und ausführen

Zum Testen die Zeilen einzeln in den Chat, in Befehlsblöcke eine pro Block, in eine Funktionsdatei ohne führenden Schrägstrich.

Drei Dinge, die die Befehle nicht für dich erledigen

Zweimal ausführen

Die add-Zeile schlägt fehl, wenn es die ID schon gibt. Um eine Leiste neu zu bauen, führ zuerst /bossbar remove aus oder lass die erste Zeile weg.

Herunterzählen

Eine Leiste zeigt den zuletzt gesetzten Wert. Ein Timer braucht eine Schleife, die sie aktualisiert; der Event-Artikel hat einen funktionierenden Countdown.

Aufräumen

Eigene Leisten werden mit der Welt gespeichert und überstehen Neustarts. Führ am Ende der Szene /bossbar remove aus, und /bossbar list zeigt vergessene.

Versionen

Java Edition 1.13 bis 26.3. Der Titel steht als {"text":"…","color":"white"} in der Ausgabe: Bis 1.21.4 liest das Spiel ihn als JSON, ab 1.21.5 als SNBT, deshalb funktioniert dieselbe Ausgabe in beiden. Die Bedrock Edition hat keinen /bossbar-Befehl.
