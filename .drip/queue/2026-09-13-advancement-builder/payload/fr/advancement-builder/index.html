Constructeur de progrès Minecraft

Les progrès sont ce que le vanilla a de plus proche d’un système de quêtes. Ils s’enchaînent en arbres, affichent une notification à la complétion et peuvent donner de l’expérience, débloquer des recettes ou lancer une fonction. Cet outil écrit le JSON et la ligne /advancement grant qui le déclenche.

Lire le guide Générateur de data packs

Les progrès vivent dans un data pack. Le générateur de data packs crée le dossier si vous n’en avez pas.

Comment utiliser le fichier

  1. Enregistrez le JSON au chemin indiqué, dans votre data pack.
  2. Lancez /reload.
  3. Attribuez-le ou remplissez la condition, puis guettez la notification.

Pour le retirer pendant les tests : /advancement revoke @s only harbor:harbor_quest_1

Note de version

Minecraft 1.21 a renommé le dossier advancements en advancement, et 1.20.5 a renommé le champ item de l’icône en id. Le sélecteur de version gère les deux.
