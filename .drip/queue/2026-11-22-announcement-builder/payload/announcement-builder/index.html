Minecraft Announcement Builder

Write the messages your server should repeat, choose where they appear and how often, and download a data pack that broadcasts them by itself. No plugins, from 1.20 to 26.3.

How to install

  1. Download the ZIP.
  2. Put it in <world>/datapacks/ (on a server, next to level.dat).
  3. Run /reload or restart.
  4. Stop it with function announce:stop, start it again with function announce:start.

Use your own namespace instead of announce if you changed it.

Version notes

The text is written with quoted keys, which every version from 1.20 to 26.3 reads. Links carry both the old (clickEvent) and the 1.21.5 (click_event) names, so they work on either side of the rename. Random order needs /random, added in 1.20.2.

How to use the builder

Pick a starting set, change the words, set the pace, and download.

Channel

Chat keeps a record players can scroll back to and is the only place a link works. The action bar is quieter and fades after a few seconds. A title takes the whole screen, so save it for rare news.

Interval and order

The pack waits the interval after every /reload, then shows one message, then waits again. In order goes through the list and starts over; at random picks any message each time, so the same one can come twice in a row.

Prefix and colors

A short gold prefix such as [Server] tells players the line is from the server, not from another player. One color per message is easier to read than several.

Check before you download

The file list shows the whole pack, and each file can be opened and copied, if you prefer to add the functions to a pack you already have.

When nothing appears

Nothing after /reload

The first message comes after one interval, not right away. To test, set the interval to 1 minute, or run function announce:next by hand.

Messages twice as often

Two packs, or two copies of this one, each schedule their own broadcast. /datapack list shows what is enabled.

A link does not open

Links work only in chat. A player who turned web links off in the chat settings cannot open them, and every player confirms a link before it opens.

Versions

Java Edition 1.20 to 26.3. 1.21 renamed functions to function (and the load tag folder with it), and 1.21.9 replaced pack_format with min_format and max_format. The builder writes whichever your version expects.
