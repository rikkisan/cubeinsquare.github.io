RUENFRDE

Minecraft-Ankündigungs-Generator

Schreib die Nachrichten, die dein Server wiederholen soll, wähle, wo und wie oft sie erscheinen, und lade ein Datenpaket herunter, das sie von selbst durchsagt. Ohne Plugins, von 1.20 bis 26.3.

Anleitung lesen Befehle für Ankündigungen

Starten mit:

Für eine einzelne Nachricht jetzt sofort reicht das Befehlsfeld unten. Für Nachrichten, die alle paar Minuten wiederkommen, lade das Datenpaket herunter.

Durchsage

Das Präfix steht vor jeder Nachricht im Chat und in der Aktionsleiste. Ein Titel hat keinen Platz dafür, dort wird es zum kleinen Untertitel über der Nachricht.

Nachrichten

Befehle

Ein Befehl pro Nachricht, fertig für die Serverkonsole. Füge eine Zeile ein, um die Nachricht einmal zu senden.

Installation

  1. Lade das ZIP herunter.
  2. Leg es in <Welt>/datapacks/ (auf einem Server neben level.dat).
  3. Führe /reload aus oder starte neu.
  4. Stoppen mit function announce:stop, wieder starten mit function announce:start.

Wenn du den Namensraum geändert hast, setz deinen statt announce ein.

Versionshinweise

Der Text steht mit Schlüsseln in Anführungszeichen, die jede Version von 1.20 bis 26.3 liest. Links tragen die alten (clickEvent) und die Namen ab 1.21.5 (click_event), funktionieren also auf beiden Seiten der Umbenennung. Zufällige Reihenfolge braucht /random, das es seit 1.20.2 gibt.

So benutzt du den Generator

Wähle ein Start-Set, änder die Worte, stell das Tempo ein und lade herunter.

Kanal

Der Chat bleibt nachlesbar und ist der einzige Ort, an dem ein Link funktioniert. Die Aktionsleiste ist leiser und verblasst nach ein paar Sekunden. Ein Titel nimmt den ganzen Bildschirm ein, heb ihn dir für seltene Neuigkeiten auf.

Intervall und Reihenfolge

Nach jedem /reload wartet das Paket das Intervall ab, zeigt eine Nachricht und wartet wieder. „Der Reihe nach“ geht die Liste durch und beginnt von vorn; „zufällig“ nimmt jedes Mal irgendeine Nachricht, dieselbe kann also zweimal hintereinander kommen.

Präfix und Farben

Ein kurzes goldenes Präfix wie [Server] zeigt, dass die Zeile vom Server kommt und nicht von einem Spieler. Eine Farbe pro Nachricht liest sich leichter als mehrere.

Vor dem Download prüfen

Die Dateiliste zeigt das ganze Paket, und jede Datei lässt sich öffnen und kopieren, falls du die Funktionen lieber in ein vorhandenes Paket einbaust.

Wenn nichts erscheint

Nach /reload passiert nichts

Die erste Nachricht kommt nach einem Intervall, nicht sofort. Zum Testen stell das Intervall auf 1 Minute oder führ function announce:next von Hand aus.

Nachrichten doppelt so oft

Zwei Pakete oder zwei Kopien dieses Pakets planen jeweils ihre eigene Durchsage. /datapack list zeigt, was aktiv ist.

Ein Link öffnet sich nicht

Links funktionieren nur im Chat. Wer Weblinks in den Chateinstellungen ausgeschaltet hat, kann sie nicht öffnen, und jeder Spieler bestätigt einen Link, bevor er sich öffnet.

Versionen

Java Edition 1.20 bis 26.3. 1.21 hat functions in function umbenannt (und den Ordner des Lade-Tags gleich mit), und 1.21.9 hat pack_format durch min_format und max_format ersetzt. Der Generator schreibt, was deine Version erwartet.
