Автоматические объявления на сервере с конструктором объявлений

Почти каждый сервер повторяет одни и те же строки: где рынок, где правила, когда следующее событие. Конструктор объявлений превращает их в небольшой датапак, который сам показывает их каждые несколько минут, без плагинов и без часов на командных блоках.

Автор: Рикки

Что лежит в паке

Скачивается обычный датапак. У каждого файла одна задача:

ФайлЧто делает
pack.mcmetaГоворит игре, для какой версии пак: pack_format до 1.21.8, min_format и max_format с 1.21.9.
function/start.mcfunctionСоздаёт счёт, который помнит последнее сообщение, и назначает первое.
function/next.mcfunctionВыбирает следующее сообщение, показывает его и назначает следующий вызов.
function/stop.mcfunctionОтменяет назначенный вызов, то есть останавливает рассылку.
tags/function/load.jsonЗапускает start при каждом /reload и загрузке мира. Если опцию выключить, ничего не начнётся, пока вы не запустите вручную.

Как работает таймер

Каждый тик ничего не выполняется. next в конце сам назначает себя снова через /schedule:

execute if score #next announce.broadcast matches 1 run tellraw @a […]
execute if score #next announce.broadcast matches 2 run tellraw @a […]
schedule function announce:next 6000t replace

Интервал задаётся в игровых тиках, 1200 в минуту, так что пять минут — это 6000t. Важен replace: когда /reload снова запускает start, назначенный вызов заменяется, а не добавляется второй, и сообщения не удваиваются. Первое сообщение приходит через один интервал после перезагрузки, а не сразу. Расписание считает игровое время, поэтому на лагающем сервере паузы немного растягиваются, и оно идёт, даже когда никого нет онлайн: @a тогда просто никого не находит.

Чат, строка над хотбаром или заголовок

Чат сохраняет запись, к которой можно вернуться, и только там ссылку можно нажать. Строка над хотбаром тише и гаснет через несколько секунд. Заголовок занимает центр экрана; префикс конструктор ставит в маленький подзаголовок над ним, поэтому хорошо работает что-нибудь вроде Суббота, 18:00 над БИТВА НА АРЕНЕ. Заголовок каждые пять минут утомляет, ставьте ему большой интервал. Статья о командах для объявлений сравнивает каналы подробнее.

По очереди или вразброс

«По очереди» каждый раз прибавляет к счёту единицу и после последнего сообщения возвращается к первому. «Вразброс» каждый раз бросает число через /random, так что одно сообщение может прийти дважды подряд; при трёх и больше сообщениях это редко заметно. /random есть с 1.20.2, поэтому для 1.20 – 1.20.1 конструктор пишет вариант по очереди и предупреждает об этом.

Ссылки и подсказки

Сообщение со ссылкой получает обе записи полей наведения и клика: hoverEvent/clickEvent для версий до 1.21.5 и hover_event/click_event для 1.21.5 и новее. Каждая версия берёт свою пару, а чужую отбрасывает, поэтому один и тот же пак работает по обе стороны переименования. Мы проверили это на серверах 1.21.4 и 26.3. Перед открытием ссылки игрок подтверждает переход, а у тех, кто выключил веб-ссылки в настройках чата, она не откроется вовсе.

Запуск, остановка и изменения

С пространством имён по умолчанию команды такие: function announce:start, function announce:stop и function announce:next (показывает следующее сообщение сразу, удобно для проверки). Чтобы потом поменять интервал, исправьте число тиков в start и в next. Чтобы убрать рассылку, удалите пак или выполните /datapack disable "file/<имя пака>", а затем function announce:stop. Два пака с одним пространством имён перезаписывают друг друга, поэтому второй рассылке, например для одной команды через @a[team=red], дайте своё.

Версии

Java Edition от 1.20 до 26.3. В 1.21 functions стала function, а tags/functions — tags/function; пак со старыми папками на 1.21+ загружается и ничего не делает. В 1.21.9 pack.mcmeta перешёл на min_format и max_format. Текст записан с ключами в кавычках: до 1.21.5 это JSON, после — SNBT. Перед публикацией мы запустили паки конструктора на серверах 26.3, 1.21.4 и 1.20.4.

Часто задаваемые вопросы

Плагин справится лучше?

Плагины вроде EssentialsX тоже умеют автоматические сообщения. Датапаку ничего не нужно ставить, он работает и в одиночной игре, и на Paper или Spigot, и переживает обновления, если пересобрать его под новую версию.

Почему после /reload ничего не произошло?

Первое сообщение ждёт один интервал. Выполните function announce:next, чтобы увидеть сообщение сразу, или на время проверки поставьте интервал в одну минуту.

/reload сбросит порядок?

Да. start обнуляет счёт, и список начинается с первого сообщения.

Куда идти дальше

Откройте конструктор объявлений или прочитайте, как работают команды для объявлений, если хотите написать разовое сообщение вручную. Для полосы, которая висит на экране во время события, есть конструктор боссбаров.
