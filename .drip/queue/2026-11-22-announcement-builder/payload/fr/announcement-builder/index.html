RUENFRDE

Générateur d’annonces Minecraft

Écrivez les messages que votre serveur doit répéter, choisissez où et à quelle fréquence ils apparaissent, et téléchargez un data pack qui les diffuse tout seul. Sans plugin, de 1.20 à 26.3.

Lire le guide Les commandes d’annonce

Partir de:

Pour un seul message tout de suite, le panneau des commandes ci-dessous suffit. Pour des messages qui reviennent toutes les quelques minutes, téléchargez le data pack.

Diffusion

Le préfixe ouvre chaque message du chat et de la barre d’action. Un titre n’a pas la place, il devient donc le petit sous-titre au-dessus du message.

Messages

Commandes

Une commande par message, prête pour la console du serveur. Collez une ligne pour envoyer ce message une fois.

Installation

  1. Téléchargez le ZIP.
  2. Placez-le dans <monde>/datapacks/ (sur un serveur, à côté de level.dat).
  3. Lancez /reload ou redémarrez.
  4. Arrêtez-le avec function announce:stop, relancez-le avec function announce:start.

Si vous avez changé l’espace de noms, mettez le vôtre à la place de announce.

Notes de version

Le texte est écrit avec des clés entre guillemets, que toutes les versions de 1.20 à 26.3 lisent. Les liens portent les anciens noms (clickEvent) et ceux de 1.21.5 (click_event), donc ils marchent des deux côtés du changement. L’ordre aléatoire demande /random, arrivé en 1.20.2.

Utiliser le générateur

Choisissez un ensemble de départ, changez les mots, réglez le rythme et téléchargez.

Canal

Le chat garde une trace qu’on peut relire, et c’est le seul endroit où un lien fonctionne. La barre d’action est plus discrète et s’efface au bout de quelques secondes. Un titre prend tout l’écran : gardez-le pour les nouvelles rares.

Intervalle et ordre

Après chaque /reload, le pack attend l’intervalle, affiche un message, puis attend à nouveau. « Dans l’ordre » parcourt la liste et recommence ; « au hasard » prend n’importe quel message, donc le même peut revenir deux fois de suite.

Préfixe et couleurs

Un court préfixe doré comme [Serveur] montre que la ligne vient du serveur, pas d’un joueur. Une couleur par message se lit plus facilement que plusieurs.

Vérifiez avant de télécharger

La liste montre tout le pack, et chaque fichier peut être ouvert et copié, si vous préférez ajouter les fonctions à un pack existant.

Quand rien n’apparaît

Rien après /reload

Le premier message arrive après un intervalle, pas tout de suite. Pour tester, réglez l’intervalle sur 1 minute ou lancez function announce:next à la main.

Messages deux fois plus fréquents

Deux packs, ou deux copies de celui-ci, programment chacun leur diffusion. /datapack list montre ce qui est activé.

Un lien ne s’ouvre pas

Les liens ne marchent que dans le chat. Un joueur qui a désactivé les liens web dans les paramètres du chat ne peut pas les ouvrir, et chacun confirme avant l’ouverture.

Versions

Java Edition de 1.20 à 26.3. La 1.21 a renommé functions en function (et le dossier du tag de chargement avec), et la 1.21.9 a remplacé pack_format par min_format et max_format. Le générateur écrit ce qu’attend votre version.
