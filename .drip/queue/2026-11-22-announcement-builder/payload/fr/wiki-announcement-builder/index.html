Des annonces serveur automatiques avec le générateur d’annonces

La plupart des serveurs répètent les mêmes quelques lignes : où est le marché, où lire le règlement, quand a lieu le prochain événement. Le générateur d’annonces transforme ces lignes en un petit data pack qui les affiche tout seul toutes les quelques minutes, sans plugin et sans horloge de blocs de commande.

Par Rikki

Ce que contient le pack

Le téléchargement est un data pack ordinaire. Chaque fichier a un rôle :

FichierCe qu’il fait
pack.mcmetaIndique au jeu la version visée : pack_format jusqu’à 1.21.8, min_format et max_format depuis 1.21.9.
function/start.mcfunctionCrée le score qui retient le dernier message et programme le premier.
function/next.mcfunctionChoisit le message suivant, l’affiche et programme l’appel d’après.
function/stop.mcfunctionAnnule l’appel programmé, ce qui arrête la diffusion.
tags/function/load.jsonLance start à chaque /reload et au chargement du monde. Sans cette option, rien ne démarre tant que vous ne le lancez pas.

Comment marche le minuteur

Rien ne tourne à chaque tick. next se reprogramme lui-même à la fin avec /schedule :

execute if score #next announce.broadcast matches 1 run tellraw @a […]
execute if score #next announce.broadcast matches 2 run tellraw @a […]
schedule function announce:next 6000t replace

L’intervalle est en ticks de jeu, 1200 par minute : cinq minutes font 6000t. replace compte : quand /reload relance start, l’appel programmé est remplacé au lieu d’en ajouter un second, donc les messages ne se doublent jamais. Le premier message arrive un intervalle après le rechargement, pas tout de suite. Le minuteur compte le temps de jeu : sur un serveur qui rame, les pauses s’allongent un peu, et il continue sans personne en ligne ; @a ne trouve alors simplement personne.

Chat, barre d’action ou titre

Le chat garde une trace qu’on peut relire, et c’est le seul endroit où un lien se clique. La barre d’action est une ligne plus discrète au-dessus de la barre d’objets, qui s’efface au bout de quelques secondes. Un titre occupe le centre de l’écran ; le générateur met votre préfixe dans le petit sous-titre au-dessus, donc Samedi, 18 h au-dessus de ÉVÉNEMENT ARÈNE fonctionne bien. Un titre toutes les cinq minutes lasse les joueurs : donnez-lui un long intervalle. L’article sur les commandes d’annonce compare les canaux plus en détail.

Dans l’ordre ou au hasard

« Dans l’ordre » ajoute un au score à chaque fois et revient au premier message après le dernier. « Au hasard » tire un nombre avec /random à chaque fois, donc un message peut revenir deux fois de suite ; avec trois messages ou plus, cela se remarque rarement. /random existe depuis 1.20.2 : pour 1.20 – 1.20.1, le générateur écrit la version dans l’ordre et le signale.

Liens et texte au survol

Un message avec un lien reçoit les deux écritures des champs de survol et de clic : hoverEvent/clickEvent pour les versions avant 1.21.5 et hover_event/click_event pour 1.21.5 et plus. Chaque version garde sa paire et ignore l’autre, donc le même pack marche des deux côtés du changement. Nous l’avons vérifié sur des serveurs 1.21.4 et 26.3. Le joueur confirme avant qu’un lien s’ouvre, et ceux qui ont désactivé les liens web dans les paramètres du chat ne peuvent pas l’ouvrir du tout.

Démarrer, arrêter et modifier

Avec l’espace de noms par défaut, les trois commandes sont function announce:start, function announce:stop et function announce:next (affiche tout de suite le message suivant, pratique pour tester). Pour changer l’intervalle plus tard, modifiez le nombre de ticks dans start et dans next. Pour retirer la diffusion, supprimez le pack ou lancez /datapack disable "file/<nom du pack>", puis function announce:stop. Deux packs avec le même espace de noms s’écrasent : donnez le sien à une seconde diffusion, par exemple pour une seule équipe avec @a[team=red].

Versions

Java Edition de 1.20 à 26.3. La 1.21 a renommé functions en function et tags/functions en tags/function ; un pack avec les anciens dossiers se charge en 1.21+ et ne fait rien. La 1.21.9 a fait passer pack.mcmeta à min_format et max_format. Le texte utilise des clés entre guillemets, du JSON avant 1.21.5 et du SNBT après. Nous avons lancé les packs du générateur sur des serveurs 26.3, 1.21.4 et 1.20.4 avant publication.

FAQ

Un plugin fait-il mieux ?

Des plugins comme EssentialsX proposent aussi des messages automatiques. Un data pack ne demande rien à installer, marche en solo comme sur Paper ou Spigot, et passe les mises à jour tant que vous le reconstruisez pour la nouvelle version.

Pourquoi rien après /reload ?

Le premier message attend un intervalle. Lancez function announce:next pour en voir un tout de suite, ou réglez l’intervalle sur une minute pendant les tests.

/reload remet-il l’ordre à zéro ?

Oui. start remet le score à zéro, donc la liste repart du premier message.

Pour aller plus loin

Ouvrez le générateur d’annonces, ou lisez comment fonctionnent les commandes d’annonce pour écrire un message ponctuel à la main. Pour une barre qui reste à l’écran pendant un événement, voyez le générateur de barres de boss.
