Automatic server announcements with the announcement builder

Most servers repeat the same few lines: where the market is, where to read the rules, when the next event starts. The announcement builder turns those lines into a small data pack that shows them every few minutes by itself, with no plugin and no command block clock.

By Rikki

What is in the pack

The download is a normal data pack. Each file has one job:

FileWhat it does
pack.mcmetaTells the game which version the pack is for: pack_format up to 1.21.8, min_format and max_format from 1.21.9.
function/start.mcfunctionCreates the score that remembers the last message and books the first one.
function/next.mcfunctionPicks the next message, shows it, and books the call after it.
function/stop.mcfunctionCancels the booked call, which stops the broadcast.
tags/function/load.jsonRuns start on every /reload and when the world loads. Leave the option off and nothing starts until you run it.

How the timer works

Nothing runs every tick. next ends by booking itself again with /schedule:

execute if score #next announce.broadcast matches 1 run tellraw @a […]
execute if score #next announce.broadcast matches 2 run tellraw @a […]
schedule function announce:next 6000t replace

The interval is in game ticks, 1200 per minute, so five minutes is 6000t. replace matters: when /reload runs start again, it replaces the booked call instead of adding a second one, so the messages never double. The first message comes one interval after a reload, not straight away. The schedule counts game time, so on a lagging server the gaps stretch a little, and it keeps running with nobody online; @a then simply finds no one.

Chat, action bar or title

Chat keeps a record players can scroll back to, and it is the only place a link can be clicked. The action bar is a quieter line above the hotbar that fades after a few seconds. A title fills the middle of the screen; the builder puts your prefix in the small subtitle above it, so something like Saturday, 18:00 over ARENA EVENT works well. A title every five minutes wears players out, so give it a long interval. The announcement commands article compares the channels in more detail.

In order or at random

In order adds one to the score each time and goes back to the first message after the last. At random rolls a number with /random each time, so a message can come twice in a row; with three or more messages that rarely matters. /random exists from 1.20.2, so for 1.20 – 1.20.1 the builder writes the in-order version and says so.

Links and hover text

A message with a link gets both namings of the hover and click fields: hoverEvent/clickEvent for versions before 1.21.5 and hover_event/click_event for 1.21.5 and newer. Each version keeps its own pair and drops the other, so the same pack works on both sides of the rename. We checked that on 1.21.4 and 26.3 servers. Players confirm a link before it opens, and players who turned web links off in their chat settings cannot open it at all.

Starting, stopping and changing it

With the default namespace the three commands are function announce:start, function announce:stop and function announce:next (shows the next message now, handy for testing). To change the interval later, edit the tick number in both start and next. To remove the broadcast, delete the pack or run /datapack disable "file/<pack name>" and then function announce:stop. Two packs with the same namespace overwrite each other, so give a second broadcast, for example one for a single team with @a[team=red], its own namespace.

Versions

Java Edition 1.20 to 26.3. 1.21 renamed functions to function and tags/functions to tags/function; a pack with the old folder names loads on 1.21+ and does nothing. 1.21.9 moved pack.mcmeta to min_format and max_format. The text components use quoted keys, which work as JSON before 1.21.5 and as SNBT after it. We ran the builder's packs on 26.3, 1.21.4 and 1.20.4 servers before publishing.

FAQ

Does a plugin do this better?

Plugins such as EssentialsX add automatic messages too. A data pack needs nothing installed, works in single player and on Paper or Spigot alike, and keeps working through updates as long as you rebuild it for the new version.

Why did nothing happen after /reload?

The first message waits one interval. Run function announce:next to see one now, or set the interval to one minute while testing.

Will /reload reset the order?

Yes. start sets the score back to zero, so the list starts again from the first message.
