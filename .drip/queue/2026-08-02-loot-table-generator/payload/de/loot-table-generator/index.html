Minecraft Loot-Tabellen-Generator

Eine Loot-Tabelle entscheidet, was aus einer Truhe, einem Mob oder einer Angel herauskommt. Sie ist eine JSON-Datei in einem Datapack, kein Befehl zum Eintippen — dieser Generator gibt dir also die Datei und sagt dir, wohin sie gehört. Stelle Pools, Gewichte und Mengenbereiche hier ein, statt Number Provider von Hand zu schreiben.

Anleitung lesen Datapack-Generator

Du brauchst einen Ort für das Ergebnis? Der Datapack-Generator baut den Ordner, in den diese Datei gehört.

Mit einer Vorlage starten

Tabelle

Der Typ sagt Minecraft, in welchem Kontext die Tabelle ausgewürfelt wird. Eine Truhen-Tabelle kann keine mob-spezifischen Bedingungen nutzen — ein häufiger Grund, warum eine Tabelle richtig aussieht und nie auslöst.

Pools

Jeder Pool wird unabhängig gewürfelt. Innerhalb eines Pools bestimmt das Gewicht die Chancen: Gewicht 10 gegen Gewicht 1 heißt zehnmal so wahrscheinlich, nicht zehn Prozent.

Datei verwenden

  1. Speichere das JSON unter dem oben gezeigten Pfad in deinem Datapack.
  2. Führe /reload aus.
  3. Teste mit /loot give @s loot harbor:harbor_dungeon

Der Befehl /loot liest eine vorhandene Tabelle — er erstellt keine. Es ist der schnellste Weg, die Chancen zu prüfen, ohne eine echte Truhe zu suchen.

Versionshinweis

Minecraft 1.21 hat den Ordner von loot_tables in loot_table umbenannt. Auf 1.21+ wird eine Tabelle im alten Ordner schlicht nie gelesen, ohne jede Fehlermeldung.
