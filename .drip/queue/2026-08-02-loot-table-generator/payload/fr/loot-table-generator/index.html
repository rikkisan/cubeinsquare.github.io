Générateur de tables de butin Minecraft

Une table de butin décide de ce qui sort d’un coffre, d’un monstre ou d’une canne à pêche. C’est un fichier JSON dans un data pack, pas une commande que l’on tape — cet outil vous donne donc le fichier et vous dit où il va. Réglez les pools, les poids et les quantités ici plutôt que d’écrire les number providers à la main.

Lire le guide Générateur de data packs

Besoin d’un endroit où mettre le résultat ? Le générateur de data packs construit le dossier auquel ce fichier appartient.

Partir d’un préréglage

Table

Le type indique à Minecraft dans quel contexte la table est tirée. Une table de coffre ne peut pas utiliser de conditions propres aux monstres, ce qui explique souvent qu’une table paraisse correcte et ne se déclenche jamais.

Pools

Chaque pool est tiré indépendamment. Au sein d’un pool, le poids fixe les probabilités : un poids de 10 contre un poids de 1 signifie dix fois plus probable, pas dix pour cent.

Comment utiliser le fichier

  1. Enregistrez le JSON au chemin indiqué ci-dessus, dans votre data pack.
  2. Lancez /reload.
  3. Testez avec /loot give @s loot harbor:harbor_dungeon

La commande /loot lit une table existante — elle n’en crée pas. C’est le moyen le plus rapide de vérifier vos probabilités sans chercher un vrai coffre.

Note de version

Minecraft 1.21 a renommé le dossier loot_tables en loot_table. Sur 1.21+, une table restée dans l’ancien dossier n’est jamais lue, sans le moindre message d’erreur.
