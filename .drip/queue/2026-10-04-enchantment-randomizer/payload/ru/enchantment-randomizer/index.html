Рандомайзер зачарований и атрибутов

Выберите предмет, получите случайный набор ванильных зачарований и модификаторов атрибутов, и заберите либо готовую команду /give, либо запись для таблицы лута — с диапазонами, зашитыми как number provider'ы, чтобы игра сама рандомизировала точное значение при выпадении, а не вы один раз здесь.

Читать гайд Несовместимость зачарований

В ваниле есть группы взаимоисключающих зачарований (защита, урон, удача/шёлковое касание и другие). Инструмент по умолчанию учитывает их — полный список в гайде.

Сгенерированный вывод

Два формата вывода, две задачи

Команда /give сразу выдаёт один конкретный предмет — вставьте в командный блок или чат. Запись для таблицы лута хранит диапазоны как number provider'ы minecraft:uniform, поэтому каждое выпадение из этой таблицы получает своё значение в игре, а не повторяет один и тот же результат.

Почему некоторые сочетания не встречаются

В ваниле есть взаимоисключающие группы зачарований — вы никогда не увидите Остроту и Разящий клинок на одном мече, или Защиту и Огнестойкость на одном шлеме. Опция "Учитывать ванильную несовместимость" применяет те же правила здесь; отключайте её только для датапака, который сознательно меняет совместимость.
