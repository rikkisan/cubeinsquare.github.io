RUENFRDE

Enchantment & Attribute Randomizer

Pick an item, roll a random spread of vanilla enchantments and attribute modifiers, and get either a ready /give command or a loot table entry — with the ranges baked in as number providers, so the game rolls the exact value on drop instead of you rolling it once here.

Read the guide Enchantment conflicts explained

Vanilla enforces incompatibility groups (protection tree, sharpness/smite/bane, fortune/silk touch, and more). This tool respects them by default — see the guide for a full list.

Generated output

Two output modes, two purposes

The /give command rolls one concrete item, right now — paste it into a command block or chat. The loot table entry keeps the ranges as minecraft:uniform number providers, so every drop from that loot table rolls its own value in-game instead of always matching this one instance.

Why some combinations never appear

Vanilla groups some enchantments as mutually exclusive — you will never see Sharpness and Smite on the same sword, or Protection and Fire Protection on the same helmet. "Respect vanilla conflicts" enforces the same groups here; turn it off only for a custom data pack that intentionally overrides compatibility.
