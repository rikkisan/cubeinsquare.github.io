RUENFRDE

Minecraft Recipe Generator

Recipes are data pack files, not commands, so this builder gives you the JSON and the path it belongs at. Lay a shaped recipe out on a 3×3 grid and the pattern and key are worked out for you — including trimming the empty rows, which is the step people forget.

Read the guide Data pack generator

The recipe file goes inside a data pack. If you do not have one yet, the data pack generator builds the folder.

How to use the file

  1. Save the JSON at the path shown, inside your data pack.
  2. Run /reload.
  3. Open a crafting table and try it.

A new recipe also has to be unlocked before it shows in the recipe book. It still works in the grid either way.

Format changed twice

1.20.5 renamed the result's item to id. 1.21.2 let ingredients be plain item ids instead of {"item": id}. A recipe copied from an older tutorial fails on a newer game and the other way round, so the version selector above rewrites the shape for you.
