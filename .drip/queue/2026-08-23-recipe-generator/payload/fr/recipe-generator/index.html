Générateur de recettes Minecraft

Les recettes sont des fichiers de data pack, pas des commandes : cet outil vous donne donc le JSON et le chemin où il va. Disposez une recette sur une grille 3×3 et le motif et les clés sont déduits pour vous — y compris le rognage des lignes vides, l’étape que tout le monde oublie.

Lire le guide Générateur de data packs

Le fichier de recette vit dans un data pack. Si vous n’en avez pas encore, le générateur de data packs crée le dossier.

Comment utiliser le fichier

  1. Enregistrez le JSON au chemin indiqué, dans votre data pack.
  2. Lancez /reload.
  3. Ouvrez un établi et essayez.

Une nouvelle recette doit encore être débloquée pour apparaître dans le livre de recettes. Elle fonctionne dans la grille dans tous les cas.

Le format a changé deux fois

1.20.5 a renommé le champ item du résultat en id. 1.21.2 a permis d’écrire les ingrédients comme de simples identifiants au lieu de {"item": id}. Une recette copiée d’un ancien tutoriel échoue sur un jeu récent et inversement — le sélecteur de version ci-dessus réécrit donc la forme pour vous.
