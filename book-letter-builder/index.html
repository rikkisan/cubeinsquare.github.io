Where this helps

  • Letters, summons, witness notes, and quest documents that need to feel like real objects.
  • Contracts, ritual instructions, and books players should keep and revisit.
  • Readable flavor text that belongs in the inventory instead of in a long tellraw chain.

Before export

  • If the item should look special, pair it with CustomModelData and a pack-backed icon.
  • Use shorter pages for letters and longer page stacks for journals or contracts.
  • If the book is meant to be signed lore, keep the author field intentional instead of filler.

How to use the builder

Write a book page by page and copy one /give command. The builder handles the quoting and escaping that usually breaks hand-written book commands.

Start from a pattern

Letter, Quest notice, Contract and Diary page load a short draft with a fitting number of pages. Replace the text and keep the shape.

Signed or writable

Signed gives a written book: title, author and generation show in the tooltip and nobody can edit the text. Writable gives a book and quill that any player holding it can open and change, which suits forms and drafts, not evidence.

Title, author, generation

Only signed books use them. Generation is Original, Copy of original, Copy of copy or Tattered; a copy of a copy cannot be copied again in a crafting grid.

Pages

Each box is one page. The book screen does not scroll, so a page should carry one beat: a greeting, a clause, a clue. Add a page rather than making one page longer.

Syntax and target

Choose the component format for 1.20.5 and newer or the NBT format for older versions, and the player selector that receives the book (@p by default).

Before you hand the book out

Read the longest page in game

Open the book and check the longest page; if text runs off the bottom, split it.

Quotes are handled

The builder escapes quotation marks and backslashes, so you can type pages as plain text.

Give it a look

A contract or a cursed diary reads better with its own name or model. The custom item builder covers names and models; the book command itself only carries the text.

Versions

Two formats: item components from 1.20.5 and NBT before that. The component output stores each page as a text component, which is how Minecraft keeps book pages from 1.21.5; on 1.20.5–1.21.4 pages were JSON strings, so if you play one of those versions, test a short book first.
